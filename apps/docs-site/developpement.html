Monorepo pnpm en TypeScript 6 (ESM) : Angular 22, NestJS 12, Drizzle, Zod 4, Vitest.

Organisation

Mise en route

pnpm install
pnpm dev:infra          # PostgreSQL, Vault, Garage, LiteLLM, Mailpit, LLM factice
pnpm build
pnpm typecheck && pnpm lint

Prérequis : Node.js 26, pnpm 12.18, Docker.

Base de données

pnpm db:generate        # nouvelle migration après modification du schéma

Les migrations sont versionnées dans packages/database/migrations et appliquées par le service migrate au démarrage.

Tests

pnpm test                       # unitaires et intégration (Vitest)
cd tests/e2e && pnpm test       # bout en bout sur la pile Compose (profil dev)

La suite de bout en bout couvre l’interface (Playwright), les parcours fonctionnels, Git contre un vrai GitLab, le SSO contre Keycloak et OpenLDAP, et la résilience (perte d’une API, du worker, pannes de S3, LiteLLM, Vault). Fournisseurs optionnels, dans tests/e2e : pnpm sso:up (Keycloak, OpenLDAP), pnpm forge:up (GitLab CE) ; sans eux, les suites concernées s’ignorent.

Images

pnpm images:build                                   # images locales cap-*:0.1.0
CAP_REGISTRY=ghcr.io/shipcove/ CAP_VERSION=0.2.0 pnpm images:build

Documentation

pnpm docs:dev           # http://localhost:5174
pnpm docs:build         # apps/docs-site/dist

Chaque page est un fichier HTML à la racine de apps/docs-site ; ajoutez-la à la navigation dans vite.config.js.

Règles du projet

  • Dépendances : seules les versions publiées depuis plus de deux semaines sont acceptées (minimumReleaseAge) ; les scripts d’installation sont refusés par défaut.
  • Contrats : toute entrée de l’API est validée par un schéma de @cap/contracts.
  • Secrets : jamais dans le dépôt, les journaux ni les réponses de l’API.
  • Décisions : un changement structurant s’accompagne d’un ADR.
