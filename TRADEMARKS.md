# Politique de marque Shipcove

Le code de Shipcove est un logiciel libre, publié sous licence **GNU AGPL v3** (voir `LICENSE` et
`NOTICE`). Cette licence porte sur le code. Elle **n'accorde aucun droit sur la marque** : le nom
« Shipcove », le logo et les signes distinctifs du projet (les « Marques ») restent réservés.

Cette politique a deux buts : permettre à chacun d'utiliser, de modifier et de redistribuer le code
librement, et garantir que les utilisateurs savent toujours s'ils utilisent la version officielle
de Shipcove ou une version modifiée par quelqu'un d'autre.

## Ce que vous pouvez faire sans autorisation

- **Utiliser Shipcove tel quel**, y compris en entreprise et pour vos clients, et le présenter sous
  le nom « Shipcove » tant que vous n'en modifiez pas le code (hors configuration).
- **Parler du projet** : articles, tutoriels, conférences, comparatifs, formations, en citant
  le nom « Shipcove ».
- **Indiquer l'origine d'un fork ou d'un produit dérivé** par une mention factuelle, par exemple
  « Basé sur Shipcove » ou « Compatible avec Shipcove ». La mention « Basé sur Shipcove » est
  d'ailleurs **obligatoire** dans l'interface de toute version dérivée (voir `NOTICE`, condition 1).
- **Garder le nom dans le code** (noms de paquets, d'images, de variables, références techniques)
  lorsqu'il est nécessaire au fonctionnement ou à la compatibilité, sans l'afficher comme nom du
  produit.

## Ce qui demande une autorisation écrite

- **Distribuer ou héberger une version modifiée sous le nom « Shipcove »**, ou sous un nom qui s'en
  rapproche au point de créer une confusion (par exemple « Shipcove Pro », « ShipCove+ »,
  « Shipkove »). Une version modifiée doit porter **son propre nom**.
- **Utiliser le nom ou le logo comme nom ou logo** d'un produit, d'un service, d'une société, d'un
  domaine ou d'un compte (réseaux sociaux, place de marché d'extensions…).
- **Laisser croire à un partenariat**, une certification ou une approbation par le projet Shipcove.
- **Vendre des produits** (goodies, offres commerciales) portant les Marques.

## Forks

Les forks sont les bienvenus. Pour un fork destiné à d'autres que vous :

1. choisissez un **nouveau nom** et un nouveau logo, et remplacez « Shipcove » dans l'interface,
   la documentation et les supports de communication ;
2. conservez la mention **« Basé sur Shipcove — https://github.com/Shipcove/shipcove »** dans
   l'interface, ainsi que les fichiers `LICENSE` et `NOTICE` ;
3. respectez l'AGPL v3, notamment la **mise à disposition du code source** auprès des utilisateurs
   qui accèdent au service par le réseau (section 13).

Un fork purement interne (non distribué et non proposé à d'autres utilisateurs) peut garder le nom.

## Demander une autorisation, signaler un abus

Ouvrez une issue sur le dépôt du projet en précisant l'usage envisagé. Le projet peut retirer une
autorisation accordée si l'usage ne respecte plus cette politique.

Cette politique peut évoluer ; la version en vigueur est celle du dépôt officiel.
